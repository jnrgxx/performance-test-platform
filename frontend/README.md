# Performance Test Intelligence Platform

> 🚧 Work in Progress

A full-stack platform for centralizing and analyzing JMeter performance test results with AI-powered insights.

## Tech Stack
- Java 21 + Spring Boot 3.5
- PostgreSQL
- React + TypeScript + TailwindCSS
- Docker

## Running Locally
\`\`\`bash
docker-compose up
\`\`\`
Backend: http://localhost:8080
Swagger UI: http://localhost:8080/swagger-ui.html
